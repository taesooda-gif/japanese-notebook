# 둘이서, 일본어

일본어가 처음인 중1 딸과 아빠가 함께 쓰는 1년 공부수첩입니다. 한자를 미리 배우지 않아도 시작할 수 있습니다.

## 가장 먼저 해 볼 것

1. 압축 파일을 풀고 **index.html**을 더블클릭해 보세요.
2. ‘딸의 수첩’ 또는 ‘아빠의 수첩’을 고르고 오늘의 루틴을 체크하세요.
3. ‘기록 보관함’에서 실제 공부 시작일을 정하세요. 기본값은 처음 연 날입니다.
4. ‘12개월 미션’에서 첫 미션을 함께 읽어 보세요.

파일을 직접 열 때의 저장 방식은 브라우저마다 다릅니다. 꾸준히 기록할 때는 아래 방법으로 만든 GitHub Pages 주소를 이용하세요. 파일로 연 수첩과 웹사이트 수첩은 저장 공간이 다르므로 기존 기록은 백업으로 옮겨 주세요.

## GitHub에 올려 가족에게 URL 보내기

코드 수정이나 프로그램 설치 없이 진행할 수 있습니다. **웹사이트에 필요한 파일은 index.html 하나**입니다.

1. [GitHub](https://github.com)에 로그인합니다. 계정이 없으면 가입합니다.
2. 오른쪽 위 **+ → New repository**를 누릅니다.
3. Repository name에 `japanese-notebook`을 입력합니다.
4. **Public**을 선택하고 **Add README**를 켠 다음 **Create repository**를 누릅니다.
5. 저장소의 **Code → Add file → Upload files**를 누릅니다.
6. 압축을 푼 **index.html 파일 자체**를 올립니다. ZIP 파일이나 상위 폴더를 올리는 것이 아닙니다. 화면 아래 **Commit changes**를 누릅니다.
7. **Settings → Pages**를 엽니다.
8. Build and deployment에서 아래처럼 선택하고 **Save**를 누릅니다.

   | 항목 | 선택할 값 |
   | --- | --- |
   | Source | Deploy from a branch |
   | Branch | main |
   | 폴더 | /(root) |

9. 수분 뒤 Pages 화면을 새로고침하고 **Visit site**를 누릅니다. 반영에 최대 10분 정도 걸릴 수 있습니다.
10. 열린 **사이트 주소**를 복사해서 형님에게 보내면 끝입니다.

주소의 모양은 `https://내GitHub아이디.github.io/japanese-notebook/`입니다. `내GitHub아이디`를 실제 아이디로 바꾸세요. 저장소 이름을 다르게 만들었다면 마지막 부분도 달라집니다. 저장소 화면의 github.com 주소와 실제 공부수첩의 github.io 주소를 구분해 주세요.

이 방법은 GitHub Free의 공개 저장소를 기준으로 합니다. 화면이 바뀌었을 때는 [공식 배포 설정 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)와 [GitHub Pages 시작 안내](https://docs.github.com/en/pages/quickstart)를 확인하세요.

## 이런 기능이 있어요

- **매일의 루틴**: 약 20분, 4가지 체크. 지난 날짜의 기록도 수정할 수 있습니다.
- **아빠와 딸의 수첩**: 각자의 일일 기록과 공부한 날 수를 따로 봅니다.
- **12개월 미션**: 매달 주차별 활동 4개, 함께하는 활동, 성장 점검으로 구성했습니다.
- **진행률과 도장**: 월별 6개 항목을 모두 체크하면 도장이 생깁니다. 1년 진행률은 총 72개 항목 중 완료한 비율입니다. 실력 점수나 시험 합격 가능성을 뜻하지 않습니다.
- **발자국과 배지**: 한 가지 이상 공부한 날을 모읍니다. 연속 기록이 끊겨도 누적 기록은 유지됩니다.
- **문자표**: 히라가나·가타카나 기본 46글자와 읽기 가리기 연습. 소리는 연결된 공식 학습 자료의 음원으로 확인합니다.
- **한 줄 추억**: 월별 메모를 남기고, 현재 미션을 인쇄할 수 있습니다.
- **백업과 복원**: 기록 보관함에서 JSON 파일을 내려받거나 불러옵니다.

## 기록은 어디에 저장되나요?

공부 기록은 **접속한 기기의 해당 브라우저에만 저장**됩니다. 서버에 전송하지 않으며 GitHub에도 올라가지 않습니다. 가족에게 URL을 보내면 그 사람에게는 새 수첩이 열립니다.

- 한 기기를 함께 사용하면 아빠·딸을 전환하며 각자 체크할 수 있습니다. 월별 미션과 메모는 함께 씁니다.
- 서로 다른 기기를 쓰면 각 기기에 별개의 수첩이 생깁니다. **자동 동기화는 지원하지 않습니다.**
- 기록을 옮기려면 기존 기기에서 **기록 보관함 → 기록 파일 내려받기**, 새 기기에서 **백업 불러오기**를 누릅니다.
- 불러오기는 현재 기록 전체를 교체합니다. 두 기기의 기록을 합치는 기능은 없습니다. 복원 전에 기존 기록도 백업해 두면 좋습니다.
- 브라우저 데이터 삭제, 시크릿 모드 종료, 주소·브라우저·기기 변경 시 기존 기록이 보이지 않거나 사라질 수 있습니다. 정기적으로 백업하세요.
- 백업 JSON은 개인 파일입니다. **GitHub 저장소에는 올리지 마세요.**

## 우리 집 학습 방법

**1~2개월:** 히라가나 → 가타카나, 인사와 소리 익히기.  
**3~6개월:** 명사 문장 → 동사·조사 → 형용사 → 과거·부정, 단어 속 한자.  
**7~9개월:** て형, 부탁·초대·위치, 문형 확장과 짧은 글 읽기.  
**10~12개월:** N5 공식 예제, 약점 복습, 모의연습과 다음 목표 정하기.

한국어 설명·원어민 음원·정답 해설이 있는 입문 교재 한 권과 함께 쓰세요. 이 수첩은 학습 계획과 기록 도구이며 완결된 강의나 N5 전체 교재를 대신하지 않습니다. 후반에는 N5 교재로 빠진 문법과 어휘를 보완하세요.

매달 대표 단어와 예문은 맛보기입니다. 수량을 채우기보다 실제 교재에서 만난 단어를 복습하세요. 한자는 `学生（がくせい）= 학생`처럼 표기·읽기·뜻을 묶어 배웁니다. 모든 음훈을 먼저 외우지 않습니다.

아빠는 정답을 아는 선생님일 필요가 없습니다. 음원과 해설을 함께 확인하는 공부 친구가 되어 주세요. 학교 시험 기간에는 줄이거나 쉬어도 됩니다. 준비가 부족하면 한 달을 더 쓰세요. **N5 응시는 선택이며 12개월 학습이 합격을 보장하지는 않습니다.**

## 잘 안 될 때

| 상황 | 확인할 것 |
| --- | --- |
| 사이트가 404로 보여요 | 배포 직후에는 기다린 뒤 다시 열어 보세요. Pages의 주소, main과 /(root) 설정을 확인하세요. |
| README만 보여요 | Code 목록 맨 위에서 소문자 `index.html`이 보이는지 확인하세요. 폴더 안에만 있다면 루트로 올리세요. |
| main이 선택 목록에 없어요 | README 또는 index.html을 먼저 올려 저장(Commit)했는지 확인하세요. |
| 화면이 예전 그대로예요 | 업로드 후 배포가 끝났는지 확인하고 브라우저를 새로고침하세요. |
| 배포가 실패했어요 | 저장소의 Actions 탭에서 실패한 실행의 안내를 확인하세요. 조직 계정은 관리자의 Pages 제한이 있을 수 있습니다. |
| 다른 기기에서 체크가 안 보여요 | 기기마다 기록이 별개입니다. 백업 파일을 불러오세요. |
| 저장 경고가 보여요 | 페이지를 닫기 전에 백업을 받으세요. 일반 브라우저 창에서 사이트를 열고 저장 공간 설정을 확인하세요. |

## 파일과 수정

배포용 파일: **index.html**. CSS, 학습 내용, 동작 코드, 그림이 모두 들어 있습니다. 외부 글꼴·라이브러리나 별도 빌드 과정이 필요 없습니다. 로컬 파일은 인터넷 없이 열 수 있고, 외부 학습 자료 링크에는 인터넷이 필요합니다. 웹사이트의 오프라인 설치·캐시는 지원하지 않습니다.

내용을 고칠 때는 index.html 안의 `MONTHS`(12개월 미션), `PHASES`(로드맵), `routineContent`(일일 루틴)를 수정하면 됩니다. 기록 형식을 바꾸지 않는 일반 콘텐츠 업데이트는 같은 사이트 주소의 저장 기록을 유지합니다. 저장소 이름·도메인·기기를 바꾸기 전에는 백업하세요.

별도 로그인, 분석 도구, 광고 또는 기록 전송 기능은 없습니다. 페이지 디자인의 그림은 자체 SVG입니다. 외부 교재나 문제를 복제하지 않고 공식 페이지로 연결합니다.
