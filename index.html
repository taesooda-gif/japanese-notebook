한자는 단어 속에서 만나요

学生（がくせい） = 학생처럼 표기·읽기·뜻을 한 묶음으로 배워요. 한국 한자 급수를 먼저 끝내거나, 한 글자의 모든 음훈을 외우지 않아도 돼요.

그날 배운 단어 3~5개를 보고, 가리고, 말하고, 다음 날 다시 만나요. 양이 많으면 1~2개로 줄여요.

아빠는 선생님보다 공부 친구

정답을 미리 알 필요는 없어요. 같은 교재·같은 음원을 사용하고, 모르는 것은 함께 찾아요. 아이가 아빠에게 설명할 기회도 주세요.

‘오늘 몇 개 맞았어?’보다 ‘오늘 무슨 말을 할 수 있게 됐어?’로 마무리해요.

우리 집의 작은 약속

평일 20분을 기본으로, 학교 시험 기간엔 5분이나 휴식으로 조절해요. 5주가 있는 달은 복습과 쉬어 가는 주로 써요. 완벽해질 때까지 같은 단계에 묶이지 않아도 돼요.

이 수첩은 학습 계획·기록 도구예요. 한국어 설명·음원·정답 해설이 있는 입문 교재 한 권을 함께 쓰고, 후반에는 N5 교재로 범위를 보완해요. 1년 뒤 시험 응시는 선택이며 합격을 보장하는 과정은 아니에요.

우리의 작은 문자표

기본 46글자

글자를 누르면 읽기를 확인할 수 있어요. 로마자는 참고용이며, 정확한 소리는 아래 공식 자료의 음원으로 들어요.

탁음·반탁음·작은 글자는 어떻게 읽을까요?
が ぎ ぐ げ ご ／ ガ ギ グ ゲ ゴ
ざ じ ず ぜ ぞ ／ ザ ジ ズ ゼ ゾ
だ ぢ づ で ど ／ ダ ヂ ヅ デ ド
ば び ぶ べ ぼ ／ バ ビ ブ ベ ボ
ぱ ぴ ぷ ぺ ぽ ／ パ ピ プ ペ ポ

기본 글자에 ゛를 붙이면 탁음, は행에 ゜를 붙이면 반탁음이 돼요. ぢ·づ는 현대 표준어에서 보통 じ·ず와 같은 소리로 나지만 표기는 구별해요.

작은 ゃ·ゅ·ょ: きゃ(kya)·きゅ(kyu)·きょ(kyo)처럼 앞 글자와 합쳐 한 박으로 읽어요. 작은 っ는 다음 자음 앞에서 한 박 막아 주는 느낌이에요. 예: きって(우표).

긴소리는 한 박 더 길게 내요. 예: おばさん(아주머니) / おばあさん(할머니), ビル(건물) / ビール(맥주). 가타카나는 보통 ー로 길이를 나타내요.

は·へ·を는 조사일 때 각각 wa·e·o로 읽어요. 문자표는 소리·획순 학습을 대신하지 않으니 음원과 함께 사용해요.

초보 부녀를 위한 교재·영상 사용법

  1. 한국어 설명, 원어민 음원, 정답과 해설이 있는 입문 교재 한 권을 골라요. 아빠도 같은 진도를 함께 나가요.
  2. 하루 한 쪽 정도를 기준으로 하되 어려운 날은 반 쪽만 해도 좋아요. 페이지 수보다 한 문장을 이해하는 데 집중해요.
  3. 듣기는 20~60초짜리 쉬운 대화를 반복해요. 먼저 듣기 → 대본·뜻 확인 → 다시 듣고 한 문장 따라 하기.
  4. 좋아하는 콘텐츠는 별도의 즐거움으로 남겨요. 한국어 자막으로 즐기다가 아는 장면만 일본어 자막으로 살펴봐요.
  5. N5 준비 단계에서는 입문 교재와 수첩의 빈 부분을 N5 교재로 보완해요. 응시 일정·접수는 지역별 공식 안내에서 확인해요.

링크로 공부수첩 나누기

별도 설치 없이 index.html 파일 하나를 GitHub Pages에 올리면 돼요.

  1. GitHub에 로그인하고 New repository를 눌러요.
  2. 이름을 japanese-notebook으로 정하고 Public, Add README를 선택한 뒤 만들어요.
  3. Add file → Upload files에서 index.html을 올리고 Commit changes를 눌러요. ZIP이나 상위 폴더 대신 파일 자체를 올려요.
  4. Settings → Pages로 가서 Deploy from a branch, main, /(root)를 선택하고 Save를 눌러요.
  5. 배포가 끝나면 Pages 화면의 Visit site로 확인해요. 보통 수분, 최대 10분 정도 걸릴 수 있어요.
  6. https://내아이디.github.io/japanese-notebook/ 주소를 가족에게 보내 주세요.

공개되는 것은 수첩 페이지예요. 체크와 메모는 기기에 저장되어 다른 사람에게 보이지 않아요. 이 수첩은 회원 가입이나 서버 저장을 사용하지 않아요.
